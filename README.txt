מפל שלישות — קבצי האתר

קבצים:
- index.html — מבנה האתר והתוכן
- style.css — העיצוב, הצבעים וההתאמה לנייד
- script.js — פתיחת חלונית ההיכרות, תפריט וקרוסלת התוצרים
- assets/mashan-logo.png — סמל חיל המשא״ן

איך לפתוח?
פתחו את index.html בדפדפן. מומלץ לערוך את התיקייה ב-VS Code.
חשוב: השאירו את הקבצים והתיקייה assets באותו מבנה כדי שהתמונות והעיצוב ייטענו.

איך להוסיף תמונה לכרטיס תוצר?
שמרו את התמונה בתיקיית assets, ואז בתוך index.html החליפו את אזור cover-placeholder בתגית img, לדוגמה:
<img src="assets/my-project.jpg" alt="צילום מסך של הלומדה">

איך להוסיף קישור?
שנו את כתובת href של project-link בכרטיס המתאים.
